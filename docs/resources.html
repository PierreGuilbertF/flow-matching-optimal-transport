Reproduce the figures

Download the Python scripts. The public repository also contains the PNG and PDF figures, numerical data, and diagnostics.

python -m pip install numpy scipy matplotlib
python python_scripts/plot_contracted_convolution.py
python python_scripts/plot_convolution_velocity.py
python python_scripts/animate_generative_flow.py --mode panels

Run the other scripts individually for the transport comparisons and additional examples. Videos require FFmpeg. The empirical optimal transport calculation uses 16,384 points and can require several GB of memory; the saved coupling is supplied in the repository.
